# 💻 Vinicius Aranda - Portfólio Moderno

Portfólio moderno desenvolvido para apresentar minhas habilidades como desenvolvedor Front-End, com design minimalista, responsivo e suporte a dois temas (Dark & Light).

---

## 🚀 Sobre o Projeto

Este projeto foi criado com o objetivo de apresentar minhas habilidades técnicas de forma visual, moderna e diferenciada dos portfólios tradicionais.

O layout foi desenvolvido com foco em:

- ✔ Experiência do usuário
- ✔ Performance
- ✔ Código limpo
- ✔ Design minimalista
- ✔ Alternância de tema (Dark/Light)
- ✔ Responsividade

---

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla JS)

---

## 🎨 Funcionalidades

- 🌙 Alternância entre tema Dark e Light
- 📱 Layout totalmente responsivo
- 🎯 Estrutura organizada para expansão futura
- ⚡ Código leve e otimizado
- 🎨 Interface moderna e profissional
